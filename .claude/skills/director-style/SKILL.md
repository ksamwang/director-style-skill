# 导演风格技能包

125 位导演，每人三层：

- **八节风格约束**：核心命题、人物关系、视觉规则、镜头语法、表演与对白、时间与剪辑、声音规则、反向约束
- **视觉配方**：参考画幅、镜头/焦段、机位与运动、色彩、光线、材质、构图
- **AI 提示文件**：图像提示、视频提示、负面提示、一致性锚点、平台适配

另有 **29 位摄影指导（DP）**，每人一份视觉档案 + 一份 AI 提示。DP 负责光、镜头、色彩、运动、格式，不负责叙事与表演。

**主用途：AI 图像 / 视频生成。** 次用途：剧本、分镜、现场调度。

## AI 生成工作流

### 1. 明确镜头

- 产物：单张图 / 镜头序列 / 视频片段
- 主体、场景、动作
- 景别、时长；画幅由用户/平台设定
- 平台：Midjourney / SDXL / ComfyUI / Runway / Kling / Sora / Veo
- 是否需要跨镜头一致性

### 2. 选主风格

读 `references/index.md`。按**核心命题 + 视觉族**选。

- 用户点名 → 直接用。
- 用户只给氛围词 → 给 2–3 个候选，各用一句话说明画面差异，再选一个。
- 不要因为“都拍长镜头”就选错人：长镜头的功能可能完全相反（凝视 / 压迫 / 等待 / 炫耀）。

### 3. 读两份文件

- `references/directors/<slug>.md` — 风格约束
- `references/prompts/<slug>.md` — 可直接用的提示基元

如果要叠加摄影指导，再读：

- `references/cinematographers/<dp-slug>.md`
- `references/prompts-cinematographers/<dp-slug>.md`

优先看：`视觉规则`、`镜头语法`、`视觉配方`、`反向约束`、`误读警告`。
film-grab 链接只是证据，不替代提示写作。

### 4. 写「AI 生成提示卡」

按 `templates/ai-prompt.md` 输出：

1. **风格锚点**：一段式英文，40–80 词，放在所有 prompt 最前。
2. **图像提示**：主体、场景、景别/构图、镜头/焦段、光线、色彩、材质。画幅由用户/平台设定，不写入提示。
3. **视频提示**：镜头运动只选一种；主体运动、时长、帧率、运动模糊分开写。
4. **负面提示**：从「反向约束」逐条转成英文 negative prompt。
5. **一致性锚点**：色彩、镜头、光线、构图、材质；再加“禁止漂移”。
6. **平台备注**：Midjourney 的参数、SDXL 的 ControlNet/IP-Adapter、视频模型的参考图与秒数。

### 5. 自检

- 是否只写了导演名字？必须落到视觉基元。
- 是否有至少一个**只属于该导演**的约束（机位、光源、材质、运动规则）。
- 图像与视频是否分开写。
- 负面提示是否来自「反向约束」，而不是通用套话。
- 跨镜头一致性是否锁了色彩、镜头、光线、构图、材质。
- 混搭时是否只保留一个核心命题。

## AI 生成提示卡（最小格式）

```
项目 / 镜头：
主风格：X（签名层：…）
副风格：Y（借用层：…，可选）

风格锚点（英文 40–80 词）：

图像提示：
- 主体 / 场景：
- 景别 / 构图：
- 镜头 / 焦段：
- 光线：
- 色彩：
- 材质：

视频提示：
- 镜头运动（只选一种）：
- 主体运动：
- 时长 / 帧率 / 运动模糊：

负面提示：
- 英文 negative prompt：

一致性锚点：
- 色彩 / 镜头 / 光线 / 构图 / 材质：
- 禁止漂移：

平台备注：
- Midjourney：
- SDXL / ComfyUI：
- Runway / Kling / Sora / Veo：
```

## 混搭

- 命题只取主风格。
- 副风格最多借两层，且不能碰签名层。
- 冲突时主风格签名层优先。
- 不要把两位导演的名字直接堆在一起；用视觉基元，模型更稳。
- 完整规则见 `references/mixing.md`。

## 导演 × 摄影（新轴）

1. 先定导演（命题、表演、时间），再选 DP（光、镜头、色彩、运动）。
2. DP 不改变导演的核心命题；冲突时导演的命题优先。
3. 组合示例：卡隆 × 卢贝兹基；库布里克 × 奥尔科特；莱昂内 × 德利科利；科恩兄弟 × 迪金斯。
4. 输出时：导演的场面/表演写进主体与运动，DP 的光线/色彩/镜头写进图像提示与一致性锚点。

## 剧本 / 分镜用法（次要）

1. 明确任务：整片基调 / 单场戏 / 分镜。
2. 按核心命题选主风格，读对应档案。
3. 输出「风格执行卡」（`templates/style-brief.md`）：机位、运动、剪辑、声音、表演。
4. 自检：命题是否落地；反向约束是否逐条通过。

## 三条反模仿原则

1. **先命题，后视觉。** 没有命题的视觉只是滤镜。
2. **一个签名，不是一套符号。** 只取这位导演最不可替代的一层。
3. **反向约束优先。** 先确定不做什么，再决定做什么；negative prompt 比 positive 更能保住风格。
