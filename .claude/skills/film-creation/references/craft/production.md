# 制作

## 核心方法

制作模块只回答两个问题：这个剧本现在能不能拍；如果能，按什么顺序、用多少天、花多少钱拍完。它不负责让剧本更好，负责让剧本变得可执行。

核心工具是剧本分解表：把每一场戏拆成可计价、可排期的元素——内外景、日夜、场地、有台词演员、群众演员、道具、动物、车辆、特技、特效、服装、发型化妆。分解表同时是预算表和日程表的原料。没有分解表就做预算，等于不知道路况就出发。

三个判断：

一、先分解，再谈钱和天数。页数只是粗略单位，真正决定成本的是元素密度和变化次数。一场八分之一页的戏，如果有儿童、狗、雨和三辆道具车，会比三页两个人在房间里说话更贵。

二、成本跟着"变化"走，不跟着"页数"走。每次转场、每次日夜切换、每次换装、每次布光，都是硬成本。排期的本质是把相同元素集中，把变化次数压到最低。

三、约束要在剧本阶段生效，不是在片场生效。写剧本时就要知道钱、场地、演员、设备在哪里；写不进这些条件的场景，最后只有三种结局：删、改、或者拍得很差。

## 可执行规则（8–12 条）

1. 每场戏先拉一张分解表，固定十二列：内外景、日夜、场地、有台词演员、群众演员、道具、动物、车辆、特技、特效、服装、发型化妆。十二列缺一列，预算就漏一项。
2. 先按场地聚合，再按日夜聚合，最后才按故事顺序排。排完把转场次数写在日程第一行，转场是第一个要压下去的数字。
3. if 同一场地在剧本里分散出现三次以上，then 把它们排进同一个拍摄日，并接受演员为此空出整天；一场戏的演员成本，通常低于一次转场的场地、运输和人员成本。
4. if 一场戏需要儿童、动物、特技、火焰、雨雪中的任意两项，then 单独给它一个拍摄日，指定一名现场负责人，并准备一个不依赖这些元素的备用拍法。
5. 每个拍摄日先拍最难的：自然光窗口、儿童、动物、特效、群众场面。对话镜头放最后，它们在任何时间都能补。
6. 用有效页数排期：对话、单机、固定光 3–5 页/天；有转场或依赖自然光 2–3 页/天；儿童、动物、动作、夜外 1–2 页/天。if 算出来一天超过 5 个有效页，then 减场或加天，不要靠"拍快点"。
7. 一个拍摄日最多一次转场。if 必须两次，then 这一天只排半天页数，另一半留给路程和重新布光。
8. 先锁不可移动的日期：演员档期、场地许可、季节与自然光、儿童工时。锁完再往里填场景；反过来排一定返工。
9. 每个拍摄日写一张"必须拿到"清单：主镜头、关键插入、定场镜头、切出镜头、干净对白与环境声。收工前逐项勾，缺的当场补。
10. if 剧本元素需要许可或授权（品牌、商标、音乐、真实地点、真实人物），then 在定稿前解决；拿不到就改写，不要指望"拍完再说"。
11. 预算留 10–15% 预备金，日程留一天缓冲。if 预备金低于 10%，then 砍一场戏，不要砍安全、餐饮、保险和声音。
12. 拍短片时先按演员改角色，不按角色找演员；能上三脚架就不手持；开拍前定好停机时间；为技术故障预留一小时；不管发生什么，把片子拍完。

## 场景检查清单（8–12 问）

- [ ] 这场戏的十二项元素都填了吗？哪一项还没有负责人？
- [ ] 这场戏有已经看过、可以到达、拿到许可的场地吗？备选场地在哪里？
- [ ] 从上一个场地到这里要多久？当天还剩几个有效小时？
- [ ] 这是日景还是夜景？日景的自然光窗口是几点到几点？
- [ ] 需要儿童或动物吗？工时、监护人、训练员都安排了吗？
- [ ] 有火、水、烟、血、车辆或武器吗？安全负责人是谁？
- [ ] 需要多少群众演员？服装从哪来？他们在哪里等、吃什么？
- [ ] 这场戏最贵的元素是什么？删掉它，故事还成立吗？
- [ ] 今天"必须拿到"的是哪三个镜头？
- [ ] 现场有没有无法避免的噪音源？对白能干净录到吗？
- [ ] 如果下雨或场地临时取消，改拍哪一场？
- [ ] 收工时素材备份了几份、在哪里、谁负责？

## 常见错误（5–8 条）

- 按故事顺序排期 → 每天都在转场，演员与场地成本翻倍，最后三天赶工 → 先按场地和日夜聚合，再排叙事顺序。
- 用总页数估天数 → 一页夜外动作戏被当成一页室内对话戏 → 用有效页数和元素难度估。
- 剧本没定稿就排期、定场地 → 每改一稿，分解表、预算、通告全部作废 → 只放行对白修改，锁住影响场地、道具、服装的改动。
- 野心超过预算（人海、火、动物、年代戏）→ 拍到一半没钱，成片残缺 → 剧本阶段列出最贵的三场戏，逐场决定删、改或换拍法。
- 剧组规模不对：太大拖慢现场，太小没人管声音和场记 → 现场失控 → 按"每个关键岗位有没有一个人"配组，不按人数配。
- 跳过定场镜头和切出 → 剪辑时没有转场材料，只能硬切或补拍 → 每个场地开机前先拍三个空镜、两个切出。
- 每个机位都拍全 → 素材量超过剪辑能力，周期拖进后期 → 每场只做"主镜头 + 必要插入"两级覆盖。
- 把声音留给后期 → 现场噪音、衣服摩擦、对白重叠无法修复 → 每场收工前听一遍，缺的当场补录。

## 练习（1–2 个）

练习一：五页分解（三十分钟）。选一个五页左右的短片片段，按十二列做分解表，标出三个最贵的元素，用 3–5／2–3／1–2 页每天的档位估一个天数。最后写一句话：如果只能保留一个场地，删掉哪几场。

练习二：条形板重排（二十分钟）。把八场戏写在八张卡片上，正面写场地、日夜、页数、特殊元素。先按故事顺序排，数转场次数和演员工作日；再按场地与日夜重排，再数一遍。比较两组数字，写下你愿意为叙事顺序多付几天。

## 与风格层的接口

**一、预算和天数直接决定镜头语法。** 机位数量、运动设备、布光次数都是时间单位。if 一天要拍四到五页、单一实景、依赖自然光，then 风格只能建立在固定机位、长镜头、现场光上；摇臂、轨道、多次布光在日程上不成立。反过来，if 风格要求大量运动镜头，then 排期必须把每个运动镜头折算成额外时间，并在预算里单列稳定器、轨道、跟焦员。

**二、场地先于调度。** 天花板高度决定能不能低角度仰拍，窗户朝向决定日景光位，电源容量决定灯的数量，环境噪音决定能不能录同期声。if 想要"低角度广角加纵深"，then 先找有层高和纵深的场地，而不是先画分镜。风格层写"空间压迫"之前，制作层要先交出可用场地清单。

**三、周期决定覆盖策略，覆盖策略决定剪辑风格。** 一天一页的戏可以正反打、多机位、每条都拍；一天五页的戏只能"主镜头加插入"两极覆盖。if 排期紧，then 风格要接受长段加跳切，把节奏交给表演和剪辑，而不是交给机位；if 排期松，then 才有条件做复杂分切和精确转场。

**四、钱决定画面里有多少"世界"。** 群众演员数量、美术密度、服装套数、场地级别，决定镜头里能出现多少人、多少物、多少层次。if 只有六个群演，then 不要写广场和集市，改用画外空间、景深遮挡、局部特写和声音暗示规模。这是硬约束，不是建议。

**五、自然光是排期问题，不是美学问题。** 可用的黄昏每天只有二十到三十分钟。if 风格规定大量黄昏外景，then 这些戏必须集中在同一场地、同一周，每个黄昏只排两到三个镜头，其余时间拍同场地的日景或夜景。风格层不能要求"每天都有完美的黄昏"。

**六、AI 生成方案受同一套约束。** 生成成本随镜头数、元素数、时长和一致性要求上升。if 额度有限，then 用固定机位、少切点、画外音、遮挡和反应镜头，把复杂动作压进一个镜头；if 需要儿童、动物、火、水或复杂群演，then 不直接生成，改用影子、反射、声音和剪辑暗示。分镜阶段就给每个镜头标注"可生成／需合成／必须实拍"，这是制作分解表在 AI 流程里的对应物。

**七、给风格层一张约束卡。** 上面写：可用场地类型与数量、总拍摄天数、每天有效页数、可用机位与运动设备、特殊元素上限（儿童、动物、特技、群演）、自然光窗口、后期与声音预算。导演风格只能在这张卡里选；超出卡片的部分，要么改剧本，要么加预算，不能靠现场加班解决。

**八、与相邻模块的分界。** 故事层决定写什么，制作层决定这些能不能被造出来，视觉与调度层在制作层给出的场地、天数、设备里做选择。制作不是风格的敌人，是风格的预算表。
