# 声音与视听

## 核心方法

声音解决的不是"给画面配什么音乐"，而是三个问题：观众相信自己在什么空间、谁在这个空间里、谁的注意力被允许放到哪里。画面证明空间存在，声音决定空间怎么被感知——混响给出大小，底噪给出时间，最远的可辨认声源给出边界。

最重要的三个判断：

**第一，声音建立空间，画面确认空间。** 一场戏的第一个声音应该先于或同时于第一个镜头出现。观众用耳朵搭好房间，画面才落地；反过来，先给全景再补声音，声音就降级成装饰。

**第二，同步是默认值，错位才是表达。** 声画点对点同步时，观众只注意内容；只有当声音提前、滞后、缺失或来自意料之外的方向，观众才意识到声音本身。值得设计的是偏离，不是同步。

**第三，沉默是可听见的空洞，不是静音。** 撤走某一层声音之后，剩下的底噪才是沉默；把轨道清空只会像设备故障。所以沉默必须先有铺垫：先让观众熟悉某个声音，再把它拿走。

这三条给出一场戏的听觉顺序：先定空间与声源，再定哪一层被突出，最后才决定音乐进不进。

## 可执行规则（8–12 条）

1. 每场戏先写声音分层表：对白、环境、动作拟音、音乐四层，各写一句功能（定位／信息／情绪／节奏）；没有功能的层删掉。
2. if 场景首次出现，then 让一个画外声源先于画面一到两秒到达，用耳朵建好空间，画面再落地。
3. 固定每个空间的三项参数：混响时间、底噪、最远的可辨认声源；同一空间全片不许漂移，换空间时三项至少改两项。
4. if 要观众听清一句台词，then 压掉同频段的其他声音（音乐中频、持续环境声），不要整体推高台词音量。
5. 声音透视跟景别走：特写给近场声（呼吸、衣料、手指、吞咽），全景给远场声与长混响；禁止所有镜头用同一混响。
6. if 出现画外声源，then 先让观众定位错，再揭示真实位置；错误定位持续多久，悬念就有多久。
7. 音乐不落在动作点上：提前半拍进入，或等动作结束后再进；与动作同帧会让音乐变成解说。
8. if 一场戏要显得更长、更慢，then 减少声音事件的数量，而不是放慢画面；声音稀疏，时间才变厚。
9. 旁白只允许两种位置：知道得比画面多，或知道得比画面少（甚至说错）；与画面信息等量的旁白是冗余。
10. 每场戏留一个不服务剧情的声音——远处的狗、楼上的脚步、冰箱嗡鸣；它负责让世界看起来不是为这场戏搭的。
11. if 跨空间或跨时间转场，then 用声音先行或声音滞后：下一场的环境声提前进入，或上一场的声音拖过剪辑点；不要用音乐盖。
12. 沉默前按顺序撤层：撤环境主体→撤音乐→留底噪，三步走完再停两到四秒；直接静音不算沉默。

## 场景检查清单（8–12 问）

- [ ] 这场戏的第一声是什么？画内还是画外？出现在第几秒？
- [ ] 声音分层表写了吗？每一层都能一句话说出功能吗？
- [ ] 主角在这个空间里听得见什么、听不见什么？"听不见"是剧情的一部分吗？
- [ ] 混响、底噪、最远可辨认声源，三项与画面空间一致吗？
- [ ] 有没有一个声音事件可以提前或延后六到十二帧来制造张力？
- [ ] 音乐第一次进入的确切时间点，理由能一句话说清吗？
- [ ] 关掉音乐，这场戏还成立吗？不成立时，缺的是画面信息还是表演？
- [ ] 沉默在第几秒？持续几秒？之前撤走了哪一层？
- [ ] 旁白说的是画面没有的信息吗？有没有一句在重复画面？
- [ ] 转场靠声音连接了吗？闭眼能听出空间变了吗？
- [ ] 有一个不服务剧情的声音吗？
- [ ] 台词有没有被环境声合理盖住一部分？盖住的部分重要吗？

## 常见错误（5–8 条）

- 用音乐标记每一次情绪转折 → 观众不再从表演和画面读情绪，情绪变成通知 → 先做无音乐版，全片只在两个点进音乐。
- 环境声从头铺到尾当"氛围" → 空间扁平、没有对比、听觉疲劳 → 每场只保留两三个可辨认声源，其余压成底噪。
- 所有镜头同一混响 → 空间不成立，特写和全景像贴在同一张纸上 → 按景别与距离分配混响和近远场比例。
- 旁白复述画面 → 信息冗余，悬念提前泄掉 → 改成信息差：多知道一点、少知道一点，或知道错。
- 把沉默做成静音轨 → 假，像故障 → 保留房间底噪，只撤人声与环境主体。
- 所有声音事件压在剪辑点上 → 机械、像节拍器 → 故意错开六到十二帧，让声音有物理惯性。
- 靠推高台词音量解决听不清 → 失真、听觉疲劳 → 用频段让位、动态处理和近场拟音。
- 转场用音乐盖过去 → 空间连续性断裂，观众不知道到了哪 → 用上一场或下一场的环境声做桥。

## 练习（1–2 个）

**练习一：盲听重建（30 分钟）。** 选一段六十到九十秒的对话戏，关掉画面听三遍，写下：空间大小与材质、几个人、谁在主导、白天还是夜里、下一个可能发生的动作。再开画面核对，标出自己听错的三处——那三处正是导演用画面补贴声音的地方。

**练习二：声音脚本（30 分钟）。** 把一场两页的戏改写成纯声音表：时间码／声源／画内或画外／所属层／是否被压掉。不许写"紧张""温暖"这类形容词，只写能被录到的声音。写完检查这张表能否脱离画面独立成立。

## 与风格层的接口

**导演档案的「声音规则」写成四栏可执行选择，不写气氛描述。** 音乐：来源（画内／画外／半画内）、功能（情绪替身／结构标记／反讽）、进入时机（动作前／后／同帧，默认前后）。环境声：每场可辨认声源数、哪类时刻整体抽离、底噪是否恒定。沉默：出现在哪个戏剧位置、持续几秒、之前撤走哪一层。旁白：信息差方向（多／少／错）、音色与录制距离（贴耳／房间感／电话感）。每条都落到"什么时候选 A 不选 B"，例如："人物失控时先撤环境声，两秒后再进音乐；绝不反过来。"

**反向约束（声音版）。** 从上面的规则反推禁止清单，逐条能在混音台前检查：不要用音乐标记每一次情绪转折；不要在每场戏结尾淡出音乐；不要让旁白解释画面；不要给闪回统一加混响滤镜；不要让所有空间听起来一样大。

**AI 视频提示。** 声音提示与画面提示分开写，只写可听见的具体声源和空间属性，不写 `cinematic sound design` 这类空词。推荐三段式：环境层 `ambient: rain on tin roof, distant traffic, room tone`；事件层 `foreground: footsteps on gravel, fabric movement, uneven breathing`；音乐层 `music: none`，或具体到编制与进入方式 `solo cello enters after the door closes`。多数视频模型不生成可靠音频，所以这段提示真正的用途是约束画面：声源要么在画面里可见，要么明确在画外；口型、呼吸、动作力度必须与所写声音对得上。需要听觉特写时，在提示里同时推近景别并写明近场声，逼模型把表演细节做足。

**与视觉、调度的接口。** 画外声源决定要不要给画外空间一个镜头；"听不见"决定人物是否回头、是否越过轴线；声音透视决定景别——要近场声就必须给特写。分镜阶段先标"这一场观众要听见什么"，再决定给什么画面；两者冲突时，以声音建立的空间为准，画面去补。
