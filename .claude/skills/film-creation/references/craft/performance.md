# 表演

## 核心方法

表演模块解决的是导演与演员之间的指令问题：下一场戏，你让演员做什么，用什么话对他说，他交回来的东西怎样判断可不可用。

最重要的一句：表演不是情绪，是动作。情绪不可直接命令，也不可重复；动作可以。演员说"我演不出来"，真正的问题通常不是他不够投入，而是他没有在对谁做什么。导演的工作不是把情绪翻译成表情，而是把情绪还原成一个人为了得到某样东西、对另一个人采取的行动。

三个判断：

一、动词先于形容词。任何指令都必须包含一个及物动词和一个对象——"让他留下""逼她承认""把她赶出去"。没有对象的动词会退化成状态，状态退化成表情，表情被镜头一放大就成了表演腔。

二、真实来自具体，不来自强度。演员在虚构环境里唯一能依靠的是具体事实：几点、在哪、手里拿着什么、对方上一句说了什么、这件事之前发生过几次。情境越具体，演员越松弛；情境越笼统，演员越用力。用力是心虚的表现，不是投入的表现。

三、表演有尺寸，尺寸由景别决定。同一段动作在全景里需要可见的身体幅度，在特写里要收敛到呼吸和视线。导演必须在开拍前把"这一条按什么景别演"告诉演员，否则近景素材全是过火，全景素材全是空白，剪辑台上无解。

## 可执行规则（8–12 条）

1. 先写动词，再排戏。每场戏为每个角色写一个及物动词短语，格式是"对谁做什么"。写不出来，说明这场戏还没有冲突，先改剧本。
2. if 演员问"我该怎么演"，then 不示范，先问他"你现在最想从对方身上拿到什么"，把答案变成一个可以用身体完成的动作。
3. if 台词里出现解释情绪的形容词或副词（"我很失望""我真的很生气"），then 让演员把它换成一个动作或一个具体物件，嘴里只留事实。
4. 开拍前给六格情境卡：地点与时间、过去一件相关的事、此刻的处境、与对手的关系、主要目标、眼前目标与障碍。缺任何一格，先补再拍。
5. 让演员在"等"的时候有活干：洗杯子、扣外套、收拾桌面。手里有真实任务，脸才会松开。
6. if 情绪早于事件出现（对方还没说完就先哭、先怒），then 让他把注意力放在对手最后一个动作上，这一条只做接收，下一条再接反应。
7. if 这一条是特写，then 把指令降到"想法级"，只给视线落点和呼吸，不给手势与走位；if 这一条是全景或群戏，then 给一个空间任务（走到某点、跨过某条线、坐下），让动作有可见的落点。
8. 一场戏只给一个主要目标。第二个目标要么降为障碍，要么降为手段；两个平级目标会让演员在两条线之间摇摆，剪辑时一条都用不上。
9. 第一条拍基线，之后每条只改一个变量：目标、障碍、节奏、尺寸，四选一。同时给三条指令等于没给。
10. 每条 take 结束时要求演员"停一拍"再松。这一拍是剪辑的落点；没有落点，剪辑只能按台词切。
11. if 一场戏有三人以上，then 给每个人一个互相冲突的具体目标，而不是让所有人"配合主角"。没有人真的在争，群戏就是背景板。
12. 排练允许即兴，开拍前必须"定分"：把即兴里有效的部分固定成明确的开始、过程、结束。即兴负责发现，定分负责可重复。

## 场景检查清单（8–12 问）

- [ ] 这场戏里，每个角色想从对方身上得到什么？能用及物动词说出来吗？
- [ ] 对手做了什么让他得不到？障碍是具体的人或事，还是抽象的"命运"？
- [ ] 开拍前三十秒演员在做什么？手里有没有一件真实的物件？
- [ ] 台词里有多少句在解释情绪？能不能删掉或换成动作？
- [ ] 演员知道自己在哪、几点、上一件事是什么吗？
- [ ] 两人的关系能否用一句话说清：谁欠谁、谁怕谁、谁在装？
- [ ] 这一条的景别是什么？演员的动作幅度匹配吗？
- [ ] 演员是在听，还是在等自己的台词？
- [ ] 情绪是否早于事件发生？
- [ ] 这一条和上一条的差别是什么？只有一个变量吗？
- [ ] 群戏里每个人的目标是否互相冲突？
- [ ] 这场戏结束时，谁得到了什么、谁失去了什么？

## 常见错误（5–8 条）

- 给结果不给动作（"再脆弱一点""更爱他一点"）→ 演员开始监视自己的脸，表演变成自我展示 → 改给"对谁做什么"。
- 导演整段示范 → 演员复制外部形态，丢掉自己的节奏，第二条起完全依赖 → 只示范一个动作或一个节奏点，其余让演员自己找。
- 让演员"想"角色的过去而不给具体物件和地点 → 内心活动变成解释，脸上没有可拍的东西 → 用一件可触摸的道具和一处可指认的地点承载历史。
- 每条 take 都给新指令 → 演员没有稳定基线，素材之间无法比较，剪辑无料 → 第一条定基线，之后一次只改一个变量。
- 近景仍按全景的幅度演 → 表情过大，可用的只有一两帧 → 开拍前声明景别，按景别缩放尺寸。
- 让演员在开机前"酝酿情绪" → 情绪在开机前已到峰值，实拍时正在回落 → 让演员做事，把情绪交给动作带出来。
- 把"自然"理解成"少动" → 画面空洞，观众读不到任何欲望 → 自然来自高度具体的动作，不是减少动作。
- 所有演员都在"把戏演好" → 群戏没有对抗，只剩轮流说话 → 给每个人一个会挡住别人的目标。

## 练习（1–2 个）

练习一：六格情境卡（二十分钟）。拿一场已经写好的戏，为两个角色各填六格，然后把两人的目标都改写成及物动词短语。检查两点：两个目标是否直接冲突；如果把目标改成"两人都想让这场对话顺利进行"，这场戏还剩什么。

练习二：三档尺寸（二十五分钟）。选一句三到五行的台词，用手机在同一机位拍三遍：全景幅度、中景幅度、特写幅度。回看时只问一个问题：连续看的时候哪一档不假。然后把三档接在一起，观察尺寸变化本身是否已经产生了节奏。

## 与风格层的接口

表演决定摄影机可以站多近。

**一、景别由"信息发生在哪里"决定。** 动作发生在手上或物件上（攥紧、放下、递出），就需要手部特写或插入镜头；动作发生在两人之间（逼近、回避、试探），就需要双人镜头保住距离；动作发生在脸上（一个决定、一次崩塌），才给近景或特写。演员用身体演，机器就退；演员用眼睛演，机器就进。反过来，如果风格要求大量特写，就必须在排练时把表演压到"眼睛级"，否则特写全是过火。

**二、镜头距离是亲密度的声明。** 摄影机越近，观众越被要求读微表情；演员如果给的是大动作，近景会变成滑稽。若风格规定"保持距离、少特写"（长镜头、广角、群像），表演就要外化为走位、手势、物件操作，让信息在全身可见。

**三、表演给剪辑提供切点。** 可切的点不是台词结束，而是动作结束、视线转移、呼吸变化。演员每完成一个动作"停一拍"，剪辑师就有了落点；如果全程一个强度、没有起落，剪辑只能按句子切，节奏必然平。这一拍要在现场要到，不能在剪辑台上找。

**四、反向约束。** if 演员只能给一种强度，then 不要设计多机位长镜头，改成分切加反应镜头，用剪辑制造层次；if 演员动作幅度大而准确，then 可以减少机位，用固定长镜头让他自己完成节奏。

**五、转成 AI 视频提示。** 不要写"悲伤地表演""情绪崩溃"，模型会生成符号化的脸。要写可观察的身体事实：视线落在哪、呼吸深浅、手在做什么、重心在哪只脚、与对手的距离、动作从哪开始到哪结束。固定句式：主体与外形 → 及物动作与对象 → 环境事实（地点、时间、物件）→ 尺寸（微／中／大）→ 节奏（缓慢／突然／停顿）→ 景别与机位。示例："中景固定机位，女人坐在桌边，手指反复抚平一张已经平整的收据；她抬头看向门口的男人，视线停住，呼吸变浅，身体没有移动。"这种句子既能给演员，也能给模型；它描述的是可拍的行为，不是不可拍的情绪。

**六、与相邻模块的分界。** 故事层给场景目标，调度层给动作的位置、时机与方向，表演层给动机、强度与细节。三者不能互相代劳：走位不能替代动机，动机也不能替代走位。
