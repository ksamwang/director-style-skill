# 视觉语言

## 核心方法

视觉语言解决一个问题：把戏里的信息——谁有权力、谁在隐瞒、谁在看谁、这里是什么地方——翻译成观众在一秒内能读出的图像变量。观众读图不靠理解，靠比较：这一镜比上一镜更近、更低、更暗，意义就产生了。

三个判断：

**一、一个镜头只有一个视觉主语。** 先决定观众第一眼看什么（脸、手、门、空椅子），再决定景别、光位、景深。画面里所有元素要么指向它，要么让开。

**二、四个变量各有分工。** 距离（景别＋焦段）管亲密度与信息量；角度（机位高度、正面/侧面/背面）管权力与态度；光（方向、硬度、光比）管隐藏与暴露；色与材质管情绪记忆与时代。一场戏里最多让两个变量“说话”，其余必须服从，否则观众读不出重点。

**三、方向是空间的语法。** 观众靠视线、动作方向、进出画方向在心里建一张地图。轴线、视线匹配、三十度原则不是教条，是保证这张地图不塌；要打破它，必须用一个镜头交代新的地图。

落到现场，顺序是固定的：先定视觉主语，再选距离（景别与焦段一起定），再选机位高度与正面／侧面，然后定主光方向与光比，最后定色板与材质。顺序不能倒——先挑镜头再找理由，画面就会漂亮而空洞。六步走完，用一个问题收尾：关掉声音，这场戏还剩下什么关系？

同一视觉母题在全片重复三次以上，才成为风格；只用一次，是装饰。

视觉句法只有三种动作：建立（让观众看见秩序）、强化（让同一秩序变紧或变松）、偏离（让画面第一次不守规矩）。偏离只发生一次，且落在戏的转折上；每场都偏离，等于没有秩序可偏离。

## 可执行规则（8–12 条）

1. 先定这场戏观众必须知道什么，再排序景别；说不出新增信息，就不要加镜头。
2. if 要压住一个人，then 机位高于他的视线、广角贴近、光从头顶或侧后方来；不要靠台词说“他完了”。
3. if 两人权力对等，then 对切用同景别、同机位高度、同焦段；一方升级时，只改其中一个变量。
4. if 观众第一次进入空间，then 先用一个能看见出入口与人物方位的镜头建地图，再切近景；不要一上来就给特写。
5. if 台词是重点，then 用中近景、平视、压暗背景、浅景深；不要用运动和强色彩抢注意力。
6. if 表演已经给出情绪，then 画面减配：静止、留白、少切；不要加运镜和配乐替演员演。
7. if 要藏信息，then 用画外空间、前景遮挡、景深或画框边缘；不要把脸裁掉当作神秘。
8. if 画面主色超过三个，then 删到两个加一个中性色，并指定谁主导。
9. if 光源没有画内动机，then 给它一个（窗、灯、招牌、火），或把灯移到有动机的位置；不要用“好看”当理由。
10. if 必须越轴，then 先用中性镜头、过肩或运动过轴交代；否则观众会以为两人换了位置。
11. if 用广角，then 让人或物贴近镜头，制造前后景比例差；不要只用广角拍大全景。
12. 先定暗部，再定补光：暗部决定画面性格，补光只负责让该看见的看见。

## 场景检查清单（8–12 问）

- [ ] 这一镜的视觉主语是什么？能在 1 秒内指出来吗？
- [ ] 有没有前景、高光、运动或饱和色抢走了它？
- [ ] 机位高度是选出来的，还是默认平视？
- [ ] 这一镜比上一镜多了什么信息？如果只是“换个角度”，能否删掉？
- [ ] 景别变化有理由吗（新信息、新权力、新空间）？
- [ ] 观众知道谁在左、谁在右、门在哪吗？
- [ ] 主光有画内动机吗？方向与窗、灯具、火源一致吗？
- [ ] 光比是为这场戏定的，还是为“看得清”定的？
- [ ] 暗部还剩下什么？是否只剩死黑一片？
- [ ] 色板是否不超过三个色相，且有明确主导？
- [ ] 焦点落在该看的地方吗？景深有没有泄露不该看见的东西？
- [ ] 把这一镜截成静帧，能读出人物关系吗？

## 常见错误（5–8 条）

1. 每镜都追求“好看” → 没有重点，观众视觉疲劳 → 每场只留一个英雄镜头，其余做减法。
2. 全部打亮、不留暗部 → 无隐藏、无威胁、无空间 → 先定暗部，再决定补多少。
3. 用广角拍一切大全景 → 边缘畸变、人物变形、空间虚假 → 广角靠近人，长焦退远拍全景。
4. 色彩全饱和、每场换色板 → 色彩失去表意，只剩滤镜 → 一个主导色贯穿，用材质和光位做变化。
5. 靠运镜制造情绪 → 情绪空心，观众只看见摄影机 → 先让表演与构图成立，运动只做加减。
6. 越轴不交代 → 观众空间错乱，以为剪辑出错 → 补中性镜头或运动过轴。
7. 景别随意跳（大全景直切大特写）→ 观众来不及定位 → 用中景或视线做桥。
8. 把参考图当风格 → 复制表面色调，丢掉光位与镜头关系 → 只提取三件事：光位、焦段、色板。

## 练习（1–2 个）

**练习一：一景三拍（30 分钟）**
选一个两人对话的短场景，用同一段台词拍三条：A 平视中景对切；B 一方高机位广角近拍；C 长焦压缩、两人同框。每条只改机位、焦段、光位中的两项，其他不变。回放时关掉声音，问自己：哪条先让你感到权力差？差在哪个变量？写下结论，下一场直接用。

**练习二：剧照拆解（20 分钟，6 张）**
找 6 张你喜欢的剧照，每张只填五项：视觉主语、机位高度、主光方向与硬度、色板（≤3 色）、景别与焦段猜测。填完横向比较：重复出现的才是风格，只出现一次的是偶然。把重复项写成 3 条自己的视觉规则。

## 与风格层的接口

**1. 转成「视觉规则」**
把本场选定的判断写成禁令句，格式“能用 X，就不用 Y”：能用前景遮挡，就不用干净单人；能用一个主光，就不用三点布光。每条必须对应一个画面变量，不写“要有氛围”。

**2. 转成「镜头语法」**
写清四项：机位高度（平视／略低／俯拍）、主焦段（广角／标准／长焦及毫米数）、运动规则（何时动、动多久、何时必须静止）、权力归属（谁被跟、谁被留在画外）。机位高度决定观众站哪一边：略低是仰视与威胁，俯拍是审判与无力。这四项直接进入导演档案的 `镜头语法` 段。

**3. 转成「视觉配方」**
固定七格：参考画幅、镜头／焦段、机位与运动、色彩、光线、材质／美术、构图。每格一到两个词，不堆形容词。配方是跨场次复用的最小集，不是这场戏的完整描述。

**4. 转成 AI 提示**
- 光：source（window／tungsten practical／neon／overcast／fire）＋ direction（side／back／top／under）＋ hardness（hard／soft）＋ ratio（low／high contrast）。缺一项，模型就滑回均匀布光。
- 色：3–5 个具体色相＋饱和度＋对比度，不写“电影感色调”。
- 材质：film grain／smoke／dust／rain／concrete／cheap wallpaper／silk，用材质替代“质感好”。
- 焦段：写毫米数与后果（24mm wide-angle distortion／85mm compression），不只写“特写”。
- 构图：centered／off-center／frame-within-frame／foreground obstruction／negative space／deep space。
- 负面提示：把「常见错误」逐条翻成英文 token，如“不要均匀补光” → `no even studio lighting, no fill light`。
- 一致性锚点：跨镜头锁五项——色板、主焦段、主光源与光比、机位高度与前景习惯、材质；任一项变化都要在下一镜给出理由。
- 画幅不写进提示：画幅是交付参数；用“横向延展／人物在边缘／纵向层次”保留构图逻辑。

示例一串就够：`low-key tungsten practical, hard side light from a doorway, 40:1 contrast, 35mm, desaturated olive and rust, smoke and peeling paint`。六项各自对应档案里的一个决定，没有一项是形容词。

**5. 转成「反向约束」**
「常见错误」天然是负面清单：打亮一切、全饱和、运镜代替表演、越轴不交代。逐条写成禁令，进入导演档案的 `反向约束`，同时进入提示卡的负面提示。检查标准：去掉导演名字，这些禁令仍然能约束画面。
