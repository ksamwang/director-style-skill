# 创作方法模块

6 个模块，来源于 `docs/` 下的 18 本电影书。不是书摘，是可执行的方法：读完能决定下一场戏怎么写、怎么拍、怎么剪、怎么生成。

## 模块

| 模块 | 文件 | 解决什么 | 主要来源 |
|---|---|---|---|
| 故事 | `story.md` | 写什么、怎么结构、场景怎么转 | 《剧本结构设计》《21天搞定电影剧本》《编剧的策略》《从文本到影像》《电影叙事学研究》 |
| 视觉 | `visual.md` | 怎么看见：景别、构图、焦段、光、色、材质 | 《电影语言的语法》《镜头的语法》《镜头在说话》《导演的摄影课》《电影照明器材与操作》 |
| 调度 | `staging.md` | 怎么走位、怎么覆盖、摄影机怎么动 | 《场面调度》《导演创作完全手册》《电影镜头设计》《电影镜头入门》 |
| 表演 | `performance.md` | 演员做什么、怎么排练、怎么给指令 | 《尊重表演艺术》《表演的艺术》 |
| 声音 | `sound.md` | 听见什么：透视、画外、沉默、音乐 | 《视听：幻觉的构建》 |
| 制作 | `production.md` | 能不能拍、怎么排期、怎么省钱 | 《创意制片完全手册》《短片的法则》 |

## 使用顺序

`story → visual → staging → performance → sound → production`

不是每次都要走完；短片可以压缩，但故事和调度不能跳过。

## 与风格层的关系

方法层决定“这场戏需要什么”，风格层决定“用谁的眼睛拍”。先完成方法层的判断，再选导演/摄影；不要让导演风格替代场面设计。

每个模块的最后一节都写了「与风格层的接口」，说明该模块的输出如何变成导演档案的视觉规则、镜头语法、反向约束或 AI 提示。

## 来源说明

18 本书的 PDF 文本层状况不一，模块按以下方式处理；所有模块都是**原创的操作性提炼**，不复制原文，不引用具体页码或书中案例。

- **story**：用 Windows OCR 识别《剧本结构设计》《21天》《编剧的策略》《从文本到影像》《电影叙事学研究》的相关章节；结构与场景规则来自这些章节，未覆盖处按通行编剧方法补足。
- **visual**：五本 PDF 的中文文本层缺失，只能锚定《电影语言的语法》的英文术语与《镜头的语法》的画幅/构图部分；正文按公认视觉语言方法撰写，标为**方法参考**。
- **staging**：四本 PDF 的中文文本层缺失，按公认调度方法撰写，标为**方法参考**。
- **performance**：《尊重表演艺术》《表演的艺术》为试读样本，有文本层；抽取了基本概念、目标训练、初次接触、角色等章节。
- **sound**：《视听》中文文本层缺失，按该书公认的概念框架与通行声音方法撰写，标为**方法参考**。
- **production**：两本 PDF 为节选本，文本层可抽取；分解表、排期、短片筹备方法取自相关章节，节选未覆盖处按通行制片方法补足。

出于版权与仓库体积考虑，`docs/` 下的 PDF 不进入公开仓库。
