# 场面调度

## 核心方法

场面调度解决的不是"画面好不好看"，而是三个连续决定：人物在空间里怎么移动、摄影机站在哪里、观众按什么顺序获得信息。它把剧本里的"谁想要什么"翻译成身体位置的变化，再把这种变化固定成可拍摄的机位与镜头顺序。

最重要的三个判断：

第一，调度先于镜头。先让演员在地面图上走通这场戏的权力变化，再决定机器放哪。如果先想机位，演员会变成填补画面的道具，动作没有因果，剪辑时接不上。

第二，一场戏只有一个空间事件。所谓空间事件，是指人物之间的物理关系发生一次不可逆的改变：某人越过界线、堵住出口、坐下、转身、把某物移到两人之间。整场戏的走位、机位、景别都围绕这一个事件组织，其余运动是它的铺垫或余波。找不到这个事件，就先别开机。

第三，覆盖不是拍得多，是保住地理与信息顺序。观众任何时候都要知道"谁在哪、和谁什么关系、下一步可能发生什么"。主镜头建立地理，覆盖镜头只回答主镜头没有回答的问题。

工作顺序固定为三层：先定地理（景、出入口、障碍），再定身体（谁移动、何时移动、移动到哪），最后定机器（机位、景别、运动）。顺序颠倒，后面每一层都在给前一层打补丁。

## 可执行规则（8–12 条）

1. 先画地面图：标出所有门、窗、固定家具、不可移动物，以及每个人物从入口到目标位置的最短路径，再让演员不说话走一遍。
2. 开拍前用一句话写出本场的空间事件，格式是"谁从哪走到哪，改变了什么关系"；写不出就删戏或换景。
3. if 一段对白超过三句且人物不动，then 给其中一个角色一个具体任务（倒水、关窗、收拾桌面），让台词挂在动作上。
4. if 两人关系要升温或破裂，then 先缩短或拉开两人的物理距离，再考虑加特写；特写是结果，不是手段。
5. 先拍主镜头，后拍覆盖；if 场景地理复杂或人物超过三个，then 主镜头必须完整交代所有出入口和人物相对位置。
6. 每处理一个 beat 只改一个变量：位置、景别、视线方向三选一；同时改三样，观众读不出因果。
7. if 摄影机要动，then 先找到画面内的运动动机（人物走动、车辆经过、门被推开、光线变化）；找不到就改成固定机位加演员移动。
8. 轴线先定后拍；if 必须越轴，then 用一个中性镜头（正面、背面或横移）过渡，或用明确的空间参照物重建方向。
9. 景别按信息递进：主镜头、双人、单人、特写；if 特写先出现，then 后面回到全景时观众会失去地理感。
10. 群戏把人物分成两到三个视觉组，用前后景和景深制造焦点；if 三组以上同框，then 用一次走位或一个声音把注意力引到当前说话者。
11. 每个人物的入画和出画都要有理由：进门、走向窗、绕过桌子，都要对应一个欲望或障碍，不做无目的的走动。
12. if 用长镜头调度，then 预设三个构图节点（起、转、落），用前景遮挡、穿过门框、人物交叉作为隐藏的切换点。

## 场景检查清单（8–12 问）

- [ ] 能否用一句话说出本场的空间事件？
- [ ] 地面图是否标出所有出入口、固定障碍和最短路径？
- [ ] 主角的目标是否能用身体动作表达（走近、挡住、坐下、转身）？
- [ ] 每个 beat 是否对应一次构图或位置变化？
- [ ] 主镜头是否独立交代了空间、人物关系和威胁来源？
- [ ] 轴线是否明确？越轴处是否有中性镜头或参照物过渡？
- [ ] 所有视线方向是否匹配？
- [ ] 每个摄影机运动是否都有画面内动机？
- [ ] 每个特写是否提供了此前没有的信息，而不是重复？
- [ ] 群戏中每一刻的视觉焦点是否唯一？
- [ ] 场面结束时的身体关系是否与开始时不同？
- [ ] 每个镜头能否用"谁—在哪—做什么—摄影机在哪"四要素写清？

## 常见错误（5–8 条）

- 先定机位再排走位 → 演员成为摆拍道具，动作没有因果，剪辑接不上 → 先在地面图上走通，再放机器。
- 用特写代替调度 → 情绪全靠脸，空间消失，观众不知道人物相对位置 → 先用距离、遮挡、高低差制造压力。
- 主镜头拍成全景记录 → 画面有地理没有信息，剪辑找不到支点 → 主镜头里必须发生空间事件。
- 摄影机无动机运动 → 观众晕眩，注意力被运动本身带走 → 每个运动先找画面内动机。
- 按台词切镜头 → 节奏碎，表演被切断，反应镜头变成装饰 → 按 beat 切，不按句子切。
- 群戏所有人站成一排说话 → 画面没有层次，焦点模糊 → 分组、给任务、安排前后景。
- 随意越轴 → 观众以为人物换了边，空间关系崩塌 → 用中性镜头过渡或重设地理。
- 长镜头没有节点设计 → 变成拖沓跟拍，信息密度下降 → 预设三个构图节点和隐藏切换点。

## 练习（1–2 个）

练习一：十分钟调度图。选一个三人场景（餐桌、办公室、审讯室），用十分钟画地面图，标出入口和障碍；写一句空间事件；用手机拍一个不剪辑的主镜头。回看时只问：观众能否在十秒内知道谁在哪、谁占上风。

练习二：无台词权力转换。取一段两分钟双人对话，删掉全部台词，只用走位、距离、高低差和遮挡表达"谁在逼近、谁在退让"。拍完后再把台词加回去，检查哪句台词其实可以被走位替代。

## 与风格层的接口

调度是风格层与镜头语法之间的转换器。风格层给出约束（长镜头还是碎切、固定还是手持、少景别还是多景别），调度层必须在约束内找到可执行的走位方案，再把它拆成可拍的镜头。

具体输出四样东西：

1. 地面图与走位线：标出门窗、家具、人物起点终点、每个 beat 的位置。
2. 机位图：每个机位的位置、高度、景别、朝向、运动路径。
3. beat 表：每个 beat 的"目标—障碍—动作—空间变化"。
4. 覆盖清单：主镜头、双人、单人、插入、反应、空镜，各拍几条，为什么。

这四样直接转成分镜表。分镜表每行至少包含：镜号、景别、机位与高度、运动、时长、画面内容（谁—在哪—做什么）、声音、剪辑点理由。调度决定其中的机位、运动、景别和剪辑点；视觉层补充焦段、光比、色彩；风格层补充质感与节奏参数。

调度还给风格层提供反向约束：if 风格要求少剪辑，then 所有信息变化必须交给走位、景深和前后景，不能依赖切镜；if 风格要求碎片化，then 调度要设计更多可切分的动作节点和反应瞬间，否则剪辑无料可用。

常见约束与调度响应对应如下：

| 风格约束 | 调度响应 | 覆盖后果 |
|---|---|---|
| 长镜头、少切 | 用走位和遮挡承担信息变化 | 镜头数少，平均镜长增加 |
| 碎切、强节奏 | 把动作拆成可切分的节点 | 镜头数多，特写与反应镜头增加 |
| 固定机位 | 用纵深、前后景、人物出入画 | 景别靠走位变化，不靠换机位 |
| 手持跟随 | 让摄影机跟随一个明确目标 | 运动镜头比例高，需防无动机晃动 |

调度与表演模块的分界也要说清：调度规定动作的位置、时机和方向，表演规定动机、强度和细节。同一个走位，演员可以演成试探，也可以演成威胁，但走位本身必须先成立。

转成视频提示时，每个镜头写成固定结构：主体与动作、空间关系、摄影机位置与运动、景别、环境、光线。调度负责前三项和景别，后两项由视觉层补。示例句式："中景，摄影机在门口内侧固定，人物 A 从画面右侧走向窗边，B 留在桌后，两人之间隔着半张桌子。"这种句子可以直接变成生成提示，也能被分镜师还原成机位。

如果提示词里写不出"摄影机在哪"，说明调度还没做完。
