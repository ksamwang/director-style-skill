# 故事

## 核心方法

故事模块解决一件事：把"我想拍一个关于 X 的片子"变成能在现场执行、能被镜头承载、能在剪辑台上成立的一系列场次。判断标准只有三条。

第一，故事不是事件清单，是冲突的升级。第一幕锁定"谁为了什么和谁对立"，第二幕把这个对立推到不归点——人物再也没有退路，第三幕结算。不归点定义故事；说不清不归点，就还没有故事。

第二，场次是因果单位。每场戏＝一个人想要什么＋什么挡着＋他做了什么选择＋局面因此变了什么。场与场之间必须是"因此"或"但是"，不能是"然后"。观众记住的不是事件，是事件之间的必然性。

第三，人物在压力下显形，主题在代价里成立。内在生活无法被拍摄，只能被障碍逼成可见的选择；主题不是一句台词，而是主角与对手各自实践一种答案，最后由结局裁决哪一种要付什么代价。

写作顺序固定：先写不归点与结局，再倒推第一幕的冲突锁定，最后填中间的场次。反过来写，通常会在第二幕后半段失去方向。

## 可执行规则（8–12 条）

1. 先写三句话：谁想要什么；谁或什么挡着；失败会失去什么。三句写不出，故事还没成立。
2. 先定不归点，再定第一幕的冲突锁定与第三幕高潮；中间每场必须是从一个点到下一个点的一步。
3. if 一场戏结束时局面没有变化，或两场之间只能用"然后"连接，then 删掉、并入相邻场景，或重写前一场结尾，让它的结果成为后一场的麻烦。
4. if 人物可以在冲突里转身离开而不付代价，then 先堵住退路或提高赌注，再写他的选择。
5. if 人物用台词解释自己是谁、想要什么，then 改成他在障碍前做的一个可见动作，让观众自己判断。
6. if 一句背景信息说得不自然，then 删掉；只留观众理解当前动作必需的信息，其余让画面与前后文补。
7. 每 10 分钟（长片）或每 30 秒（短片）给一个新信息，改变观众对前情的理解；同一强度的压力连续三场，观众就会适应，换一种压力再升级；反转要重估前面，不只是吓一跳。
8. 主题写成问题，不写成答案；主角与对手各持一种答案，结局只显示代价，不宣布对错。
9. 对手是主角命题的反面，不是单纯的坏人；人物从钩子逆向工程：先写故事需要他完成的动作，再补他为什么会这样做；不改变任何选择的配角删掉或合并。
10. 开场第一页给地点、时间、基调和人物；第三页用一句台词或一个动作提出中心问题；第十页观众必须已经知道谁想要什么、谁挡着。
11. if 观众需要知道"谁在看"，then 先定视点：观众视点（知道得比人物多）、人物视点（知道得和人物一样多）、旁知视点（只跟一个人）；一场戏内不混用。
12. 短片、广告、MV：从冲突已经发生的时刻开始；把前史压成一个动作、一个声音或一个物件，不用字幕交代。

## 场景检查清单（8–12 问）

- [ ] 这场戏谁想要什么？能写成一个带宾语的动词句吗？
- [ ] 谁或什么在阻挡？是人物、环境，还是时间？
- [ ] 开场第一个动作，能让观众知道人物正在做什么吗？
- [ ] 结束时局面具体变了什么：信息、关系、权力、位置、资源？
- [ ] 变化是人物选择造成的，还是巧合或外力造成的？
- [ ] 删掉这场戏，下一场是否仍然成立？若是，为什么还留着？
- [ ] 人物说的和做的是否矛盾？潜台词落在哪个动作上？
- [ ] 观众此刻比人物知道得多、少，还是一样？这个信息差被用了吗？
- [ ] 这场戏把冲突往不归点推了多少？推不动，是否该并场？
- [ ] 有没有一句台词是在向观众解释背景？能否改成动作、道具或环境？
- [ ] 最后一个动作或画面，能勾住下一场吗？
- [ ] 视点是否一致？观众始终知道自己在跟谁看吗？

## 常见错误（5–8 条）

1. 事件清单代替因果链 → 观众看得热闹却不期待 → 每场结尾用"因此/但是"重写连接。
2. 先写人物性格，再补行动 → 人物像说明书，演员无从下手 → 先设障碍，让选择暴露性格。
3. 开头解释世界观 → 对话假、节奏慢 → 删到观众刚好能跟上，缺口交给画面。
4. 第二幕靠加人物、加怪物续命 → 结构散、赌注不升 → 升级同一冲突的代价，不开新线。
5. 反转只为吓一跳，不改变理解 → 廉价，观众觉得被骗 → 反转必须让前面的信息被重新解释。
6. 主题靠角色演讲宣布 → 说教，人物变成传声筒 → 让两种答案在情节里碰撞，用结果说话。
7. 高潮解决的不是第一幕提出的问题 → 观众离场时不满足 → 高潮必须回答开场那句问题。
8. 短片按长片比例压缩 → 前两分钟全在铺垫 → 从冲突已发生处开场，前史压进一个细节。

## 练习（1–2 个）

**练习一：三卡因果链（25 分钟）**
三张卡分别写：不归点、第一幕冲突锁定、高潮，各一句。然后用五个"因此/但是"把三点连起来；任何一处只能写"然后"，就重写前一张卡的结果，直到它自然制造下一张卡的麻烦。

**练习二：关灯讲故事（20 分钟）**
不看笔记，把故事讲给一个没听过的人，录音。回放时只标两种时刻：对方走神的地方，是场景连接断了；对方追问的地方，是信息没给够。只改这两处，其余不动。

## 与风格层的接口

故事层输出五样东西，直接进入风格层与输出层：logline（一句话问题）、theme question、主角的 want／need／flaw、不归点、每场的 goal／obstacle／turn。风格层不改变这五项；冲突时故事优先。

**1. 转成导演选择。** 命题决定镜头伦理：要观众与主角一起发现，就用受限视点（跟人、少给全知）；要观众先于人物知道危险，就用观众视点（悬念）。不归点决定影片中段的视听转折：在此之前，镜头可以留退路（空间开阔、出口在画内）；在此之后，退路必须消失（门关上、景别收窄、环境声抽空、光比加大）。结局的语气由"代价是否被看见"决定，不由台词决定。

**2. 转成 DP 的三段视觉规则。** 第一幕给信息：景别偏宽、光比偏低、色板完整；第二幕逐步收紧：焦段变长、景别变近、光比升高、色板减少；第三幕只留一个视觉母题，并与开场形成同构图或反构图。主题的正反两种答案各配一套可复用的视觉语法（暖／冷、软／硬、满／空），分别绑定主角与对手；观众在比较中读到命题，不需要解释。

**3. 转成调度与表演的交接单。** 每场只交三行：谁想要什么（及物动词）、谁挡着、结束时什么变了。调度据此安排权力位置与空间事件；表演据此写 action。故事层不规定走位与机位，只规定"必须发生变化的东西"。

**4. 转成剪辑。** 用叙事学的时距决定每段长度：省略（跳过不重要）、概略（压缩过程）、场景（实时对抗）、停顿（描写与呼吸）。转场优先用"因此／但是"的视觉等价物：动作匹配、声音先入、构图对位；不要用"然后"式的淡入淡出串场。闪回必须有视觉区分（色彩、画质、画幅、声音），否则观众会把过去当成现在。

**5. 转成 AI 提示。** 每个镜头先写动作句：谁—在哪—想要什么—被什么挡住—做了什么。图像提示只写可见证据（身体状态、道具、光、空间），不写主题词与情绪词；模型不懂"孤独"，只懂"一个人坐在没开灯的房间里，桌上有两副餐具"。视频提示一镜只给一个视点与一种运镜：写清"镜头属于谁"（观众／人物），否则模型会给出无归属的漂移镜头。负面提示从本模块的常见错误转写：`no theme speech, no exposition dialogue, no unmotivated coincidence`。跨镜头一致性靠故事事实锁定：同一场的时间、天气、人物伤势、道具位置，比风格词更能防止漂移。

**6. 转成反向约束。** 风格不能替代冲突：任何镜头、光效、运镜，如果回答不了"这场戏谁想要什么、什么变了"，删掉。视觉奇观只能加在转折点上，不能加在铺垫上。
