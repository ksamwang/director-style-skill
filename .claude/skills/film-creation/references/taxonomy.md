# 风格族谱与近亲替代

> 一位导演可以属于多个族。族谱用于**找替代**，不是用于贴标签。
> 选人时先问“这场戏需要哪一种功能”，再找对应族。

## 1. 古典叙事与类型工艺

**核心问题**：如何让因果、空间、表演在一个透明的系统里运转？

**导演**：约翰·福特、比利·怀尔德、希区柯克、斯皮尔伯格、科波拉、斯科塞斯、库布里克（部分）、克里斯托弗·诺兰、萨姆·门德斯、弗兰克·达拉邦特、大卫·里恩、朱塞佩·托纳多雷

**替代规则**：
- 要更冷、更控制 → 芬奇
- 要更作者化、更身体 → 斯科塞斯
- 要更神话、更大众 → 斯皮尔伯格
- 要更宿命、更几何 → 库布里克

## 2. 类型解构与暴力

**核心问题**：类型规则如何被反转、引用、升级？

**导演**：塔伦蒂诺、科恩兄弟、芬奇、朴赞郁、奉俊昊、杜琪峰、吴宇森、莱昂内、北野武、波兰斯基、让-皮埃尔·梅尔维尔、达伦·阿罗诺夫斯基、亚利桑德罗·冈萨雷斯·伊纳里图

**替代规则**：
- 要仪式化、歌剧化 → 莱昂内 / 吴宇森
- 要冷峻、宿命 → 杜琪峰 / 芬奇
- 要阶级寓言 → 奉俊昊
- 要身体恐怖与华丽 → 朴赞郁
- 要突然的、无预兆的暴力 → 北野武

## 3. 极简、固定与日常

**核心问题**：如何用最少的摄影机运动，让日常显出重量？

- 要身体、空间、时间 → 蔡明亮
- 要冷面幽默 → 考里斯马基
- 要重复、结构、尴尬 → 洪常秀

## 近亲选择的三个陷阱

1. **把“同族”当“同风格”。** 小津和哈内克都爱固定机位，但一个要秩序，一个要暴力。
2. **把“题材”当“命题”。** 都拍家庭，不等于都在问同一个问题。
3. **把“表面符号”当“签名”。** 长镜头、对称、霓虹、黑白都不是签名；签名是“为什么必须这样拍”。

## 摄影指导的五族

1. **自然光 / 长镜 / 浸入**：卢贝兹基、托尔、莱斯涅、达维奥、普列托、莫里森
2. **硬光 / 高反差 / 深焦**：理查森、迪金斯、卡明斯基、威利斯、托兰、奥尔科特
3. **色彩 / 格式 / 史诗**：斯托拉罗、昂斯沃斯、杨、沙姆罗伊、瑟蒂斯、德利科利
4. **现代 / 数字 / 类型**：范霍伊特玛、菲斯特、菲奥雷、劳斯特森、利巴蒂克、坎迪
5. **风格化 / 作者合作 / 古典**：鲍尔豪斯、方格、埃尔斯维特、霍尔德、鲁滕贝格

选 DP 时先问：这场戏需要自然光、硬光、色彩、数字现代感，还是古典片厂？
